# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code.

This project is pinned to **Expo SDK 54** on purpose: it is the newest SDK the public
App Store / Play Store build of Expo Go can open. Do not upgrade `expo` (or any
`expo-*` package) past SDK 54 until the store version of Expo Go supports a newer SDK.
