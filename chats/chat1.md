물때(Multtae) 낚시 앱의 "로그인" 화면을 디자인해줘. (모바일, 페이지 전체)

## 목표
미로그인 사용자의 첫 진입 화면. 최소한의 입력으로 소셜 로그인을 
시작하게 하고, 서비스 가치를 짧게 전달한다.

## 레이아웃 (위→아래)
1. 서비스 가치 제안 영역 — 로고/브랜드 + 낚시 기록 앱이라는 
   가치를 전달하는 비주얼
2. "둘러보기" 진입 링크 (보조 링크 스타일, 서비스 소개 3장 캐러셀로 연결)
3. 소셜 로그인 버튼 3개 (세로 스택): 카카오 → 구글 → Apple
   - 각 제공자의 공식 브랜드 가이드 스타일 준수
4. 하단 클릭랩 문구 (고정 문구, 작은 텍스트):
   "계속하면 [이용약관]·[개인정보처리방침]에 동의하며, 
   만 14세 이상임을 확인합니다."
   - [이용약관], [개인정보처리방침]은 탭 가능한 링크 (인앱 웹뷰로 열림)

## 상태 디자인
- 로그인 진행 중: 선택한 버튼은 로딩 상태, 나머지 버튼은 비활성
- 오류 안내 영역: 버튼 영역 근처에 인라인 표시
  - "로그인을 취소했어요."
  - "네트워크 연결을 확인한 뒤 다시 시도해 주세요."
  - "로그인에 실패했어요. 잠시 후 다시 시도해 주세요."

## 하지 않는 것
- 이메일/비밀번호 입력 폼 없음
- 별도 약관 동의 체크박스 단계 없음
- 회원가입 버튼 없음 (소셜 로그인이 곧 가입 시작)

## 함께 만들 화면 (프로토타입 연결용)
- 둘러보기 캐러셀 3장 (스킵 버튼 포함, 완료/스킵 시 로그인 화면 복귀)
